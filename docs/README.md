## Orden de lectura recomendado para quien llega

1. [`README.md`](../README.md) de la raíz.
2. [Plan del equipo](tasks/00-resumen.md) y el brief de tu área.
3. [Visión general](architecture/00-vision-general.md) y los documentos de arquitectura que cita tu brief.
4. El `README.md` de cada módulo que vas a tocar: describe su responsabilidad, su API y qué falta.
